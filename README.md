# PK IT Jobs

PK IT Jobs is a robust, responsive React-based platform that bridges the gap between ambitious tech talent and visionary hardware/software companies. This web application features comprehensive portal experiences tailored directly to the authenticated user's role:

- **Student / Developer Roadmap**: Tools to build interactive digital CVs, link live portfolio assets, and discover opportunities.
- **Recruiter Hub (Company Portal)**: Allows employers to identify high-quality applicants, source verified talent, and manage technical screenings.
- **Admin Management System**: Oversee analytics, manage user roles, screen portfolios, and configure overall security settings.

## Core Features
1. **Interactive Role-Based Routing**: Displays unique sidebars, statistics, and tool layouts dynamically based on whether you are logged in as a Student, Recruiter, or Admin.
2. **Beautiful Modern UI**: Constructed on the powerful utility-first tailwindcss frameworks.
3. **Advanced CV Builder**: Intuitive builder to link external portfolios (e.g. GitHub/Live Sites), describe tech stacks, and showcase professional experience.

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) installed on your machine.

### Installation & Run Instructions
1. Clone the repository: `git clone https://github.com/syedsahilshah1/PK-IT-Jobs.git`
2. Navigate into the target directory.
3. Install dependencies by running:
```bash
npm install
```
4. Start the local development server:
```bash
npm run dev
```

## Tech Stack
- Frontend: HTML5, JavaScript, React, Tailwind CSS v4
- Tools: Vite, Lucide-React, PostCSS
